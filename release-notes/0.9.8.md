**The gear list only shows what the job can wear.**

- CatsEyeXI custom gear (the Incursion armor sets and the like) used to show for every job. Now a job's gear list only offers the pieces the game says that job can wear; custom gear with no job data at all still shows for everyone.
- Custom entries (HELM, Warp, Misc...) aren't tied to a job, so their gear list still shows everything that fits the slot.
- If a set already has a custom piece the game says the job can't wear, Checks warns about it.
